# Double Jump — Fabric 1.20.1

Мод добавляет один дополнительный прыжок в воздухе.

## Сборка
1. Нужна Java 17 и интернет для загрузки Gradle/Fabric-зависимостей.
2. Открой папку проекта в среде разработки с поддержкой Gradle или в терминале.
3. Выполни `gradle build` (либо `./gradlew build`, если добавишь Gradle Wrapper).
4. Готовый JAR будет в `build/libs/`.

## Установка на Android
1. Собери мод на компьютере или в среде, где можно запустить Gradle с Java 17.
2. Скопируй JAR из `build/libs/` в папку `mods` своего Fabric-профиля Minecraft 1.20.1.
3. Убедись, что в профиле установлен Fabric API для Minecraft 1.20.1.
4. Запусти игру и нажми прыжок ещё раз, пока персонаж находится в воздухе.

## Важно
Это клиентский мод. Поведение в одиночной игре ожидается лучше всего; на серверах мод может не работать корректно из-за проверки движения сервером.
Проект содержит исходники, но не готовый собранный JAR. Для сборки нужны Java 17 и загрузка зависимостей через Gradle.
